# 想做餐饮，请问扫码点餐怎么弄呢?
获取源码：ym7k.com/18044/
SaaS 租用：注册即用，按年付费几千到一万多，含点餐、收银、后厨打印、简单营销。适合单店、不想碰代码的。缺点是数据不在自己手里。

买现成源码：几百到几千，部署自己服务器。认准有公司主体、能开发票、带更新服务的；注意核心文件是否加密、有无授权回调。

定制开发：几万起，适合连锁多店、要分账、有特殊流程的。

扫码点餐核心流程：顾客扫桌码 → 进入小程序 → 浏览菜单 → 加购物车 → 下单 → 微信支付 → 后厨打印 → 上菜 → 加菜/结账。

要准备什么：

营业执照 + 食品经营许可证

微信小程序认证（300 元/年）

微信支付商户号

云打印机（飞鹅/易联云）

桌码（每桌一码）

常见坑：号称全开源但核心加密；授权回调跑路后系统瘫痪；桌码静态、沽清假、打印机只支持单一品牌；多店资金二清违法。

合规红线：ICP 备案 + 经营性 ICP 许可证、食品经营许可证、微信餐饮类目资质、多店代收代付走分账别二清。
